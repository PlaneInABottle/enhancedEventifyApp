## 🧪 Test-Driven Development Focus

This project strictly follows TDD principles:
- **RED**: Write failing tests first
- **GREEN**: Write minimal code to make tests pass
- **REFACTOR**: Improve code while keeping tests green

Every feature, component, and utility is developed using the TDD cycle. See our [Test-Driven Development Guide](./testing/test-driven-development.md) for detailed implementation practices.
